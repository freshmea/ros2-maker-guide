## 읽고 실행하기

1. 1장에서 ROS2의 구성과 학습할 내용을 살펴봅니다.
2. 2~3장에서 개발 환경을 준비하고 Talker·Listener 통신을 확인합니다.
3. [30분 Quick Start](../README.md#quick-start)에서 저장소의 Python 예제를 실행합니다.
4. [전체 목차](../BOOK.md#목차)에서 다음 학습 내용을 확인하고, [부크크에서 전자책을 구매](https://bookk.co.kr/bookStore/6aa76a46dc64fe8c7e11a5e1)할 수 있습니다.
